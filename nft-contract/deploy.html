Deploy CrownRacerCards

Crown Racer Cards — the Crown Race NFT collection (2,222 cards) for crownrace.site — owner deploy page

This page deploys the CrownRacerCards ERC-721 contract from your own wallet on BNB Chain (chainId 56). The constructor takes three arguments — the Binance Agent ID (.ai) registry, the metadata base URI, and the pre-assigned paid-block tier bytes — all prefilled below. The tier bytes come from the published launch shuffle (seed + SHA-256 commitment in the project repo); do not change them — the hosted metadata is generated from the same assignment. The mint starts CLOSED (mintOpen = false): deploying never opens it. Opening the mint is a separate, explicit step (step 03) that only you can trigger. Every transaction is signed in your wallet; this page never asks for a seed phrase or a private key.

04

Next steps after deploying

  1. Check the address. Open the contract on BscScan (link in step 02) and confirm it is the CrownRacerCards you just deployed.
  2. The mint stays closed for now. Do not open it in step 03 until Muse confirms crownrace.site is live with the metadata (2,222 JSONs + images under /nft/) and the mint section wired to this contract — otherwise wallets could mint cards whose metadata is not up yet.
  3. Send the address to Muse. Copy the summary box below and send it in one paste. Muse wires the address into the site's Cards mint section and the agent surfaces, then re-pushes.
  4. Then open the mint in step 03 (owner wallet only) when Muse says the live site is verified.
  5. Announce last. The launch post via @PlayCrownRace goes out only after the site is live and the mint is open.
